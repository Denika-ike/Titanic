# Titanic
Прогноз категории людей которые имели больший шанс выжить

- `data/` — оригинальные и очищенные данные.
- `notebooks/` — EDA и построение моделей.
- `models/` —  обученная модель.
- `reports/figures/` — визуализация.

  Итоги исследования (EDA)
- **Пол** оказался решающим фактором: женщины выживали значительно чаще.
- **Класс каюты**: пассажиры 1-го класса имели приоритет при спасении.
- **Возраст**: дети имели более высокие шансы на выживание в сравнении со взрослыми мужчинами.

  Результаты моделирования
- **Точность (Accuracy)**: 82%.
- **Метрики (F1-Score)**: 0.74 для класса "Выжил" и 0.84 для класса "Погиб".
